# Wiskunde – leermaterialen

## Structuur
- Mappen volgen `klas/onderwerp/`, bijv. `vwo2/lineare-formule-3-2/`.
- Elke onderwerpmap bevat:
  - `index.html` – bord-presentatie
  - `docent.pdf` – docentenvoorbereiding
- `index.html` in de root is een overzicht met links naar alle lessen, per klas. Voeg een nieuwe les hier ook toe.

## Naamgeving
- Mapnamen: kleine letters, streepjes, geen spaties of punten (dus `3-2`, niet `3.2`).

## Git
- Commit-berichten kort, in het Nederlands.
